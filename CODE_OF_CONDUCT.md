# Code of Conduct

## The short version

Be decent. This is a small project run by one person, and the bar for participating in it
is simply that other people should not regret interacting with you.

## What that means in practice

- Assume the person on the other end is doing their best with incomplete information,
  because they usually are.
- Criticise the code, the docs, or the decision — not the person who wrote it.
- "This is wrong and here is why" is welcome. Contempt is not.
- English is not everyone's first language, and not everyone has your context. Answer the
  question that was meant, not the one that was typed.

## Not acceptable

Harassment, personal attacks, discriminatory language, sexual attention or imagery,
deliberate intimidation, sustained disruption, or publishing anyone's private information.

This applies in issues, pull requests, commit messages, and any other space where you are
identifiably participating in this project.

## Enforcement

Report a problem by emailing the address on the maintainer's GitHub profile, or through
GitHub's own reporting tools if you would rather not contact the maintainer directly.

Reports are read. Depending on what happened, the response ranges from a request to
change behaviour up to a block from the repository. The maintainer's decision is final —
there is no committee here, and pretending otherwise would be theatre.

Reporting something in good faith will never itself be held against you.

## Scope

This applies to project spaces, and to public spaces when someone is representing the
project.
