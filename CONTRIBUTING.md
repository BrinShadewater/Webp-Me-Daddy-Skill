# Contributing

This is a small tool maintained by one person, so here is the honest version rather
than a template.

## What is welcome

- **Bug reports.** Especially with the input that broke it. That is the fastest possible
  contribution — most edge cases here came from a real file behaving unexpectedly.
- **Small, focused pull requests.** A fix with a clear description of what was wrong.
- **Documentation corrections.** If something in the README was misleading, it was
  misleading for everyone who read it.

## What to expect

Response times depend on whether this tool is currently in the middle of the work it was
built for. Please do not read silence as dismissal. Issues are read.

Large refactors or new subsystems are unlikely to be merged unprompted — open an issue
first and let's agree on the shape before you spend real time on it.

## Before opening a pull request

- Run the tests: `python scripts/test_prepare_image.py`. They should pass before and after your change.
- Keep the existing style. Match the file you are editing rather than the way you would
  have written it from scratch.
- One concern per pull request.
